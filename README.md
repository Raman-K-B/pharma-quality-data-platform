# Pharma Quality Data Platform

## Project Overview

This project demonstrates an end-to-end Data Engineering solution for pharmaceutical quality and compliance data using Microsoft Fabric, SQL, and Power BI.

The platform analyzes:

- Deviations
- CAPA
- Change Controls
- Compliance Metrics
- Quality KPIs

---

## Business Problem

Pharmaceutical organizations generate quality-related records across multiple systems.

Business users need centralized reporting and analytics to monitor:

- Open Deviations
- CAPA Effectiveness
- Change Control Trend Analysis
- Compliance Status
